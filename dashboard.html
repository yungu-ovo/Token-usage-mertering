指标口径说明

成本归属时刻：按请求实际发生时刻计入，与账单出账日无关，因此与厂商账单可能存在跨日差异。
统计时区：本地时区（UTC+8），自然日 00:00–24:00。
成本来源优先级：① 厂商返回的 usage.cost ② 内置价格表 × token 数。两者不一致时以 ① 为准，并在明细中标记 cost_source。
币种：USD 为基准币种，切换 CNY 时使用当日汇率并标注汇率日期。
缓存命中率：缓存读 token ÷（缓存读 token + 全新输入 token）；缓存写不计入分母。
缓存节省：缓存读 token ×（输入单价 − 缓存读单价），按各模型单价分别计算后求和。
单请求平均成本：区间总成本 ÷ 区间成功 + 失败请求总数（含失败请求）。
月末预测：本月日均成本 × 当月自然日天数，属粗略线性外推，仅供参考。
去重规则：同一请求的流式写入按 request_id 去重，仅保留 output_tokens 最大的一条，避免重复计数。
数据边界：仅采集 token 计数、模型、时间与成本字段，不读取、不存储任何 prompt / 回答正文。

本页面为产品设计原型，全部数字均为虚构示例数据，不代表任何真实用量。设计参考对象包括 llmcost、TokenBurn、tokentop、token-dashboard、ai-usage-dashboard、TOKEN-METER、llm.report、LiteLLM 及 Langfuse / Helicone / OpenLLMetry 等开源项目的公开说明（仅借鉴通用信息架构与功能模式，未复制其界面、文案或代码）。
