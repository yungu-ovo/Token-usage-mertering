指标口径说明

成本归属时刻：按请求实际发生时刻计入，与账单出账日无关，因此与厂商账单可能存在跨日差异。
统计时区：本地时区（UTC+8），自然日 00:00–24:00。所有「今天 / 本月」均按本地自然日切分。
双口径：本页主口径为 API 等价成本（token × 价格表），便于跨模型比较；厂商口径（积分 × 折算率）并行展示，折算率未校准时标注「待校准」。
成本来源优先级：① 厂商返回的 usage.cost ② 内置价格表 × token 数。两者不一致时以 ① 为准，并在明细中标记 cost_source。
币种：USD 为基准币种，折算汇率带日期标注，不联网取实时汇率。
缓存命中率：缓存读 token ÷（缓存读 token + 全新输入 token）；缓存写不计入分母。
缓存节省：缓存读 token ×（输入单价 − 缓存读单价），按各模型单价分别计算后求和。
单请求平均成本：区间总成本 ÷ 区间请求总数（含失败请求）。
月末预测：本月日均成本 × 当月自然日天数，属粗略线性外推；样本不足 3 天时不做外推并明确标注。
金额精度：内部以整数微美元（1e-6 USD）存储与计算，全程不使用浮点；构成区与折线各分项之和经配平，恒等于总额。
去重规则：同一请求的流式写入按 request_id 去重，保留 output_tokens 最大的那条记录，避免重复计数。
未识别模型：模型名不在价格表内时成本记为 0 并触发告警，绝不按「猜测单价」静默计入。
数据边界：仅采集 token 计数、模型、时间与成本字段，不读取、不存储任何 prompt / 回答正文。

本页数据来自本机 WorkBuddy 会话转录的本地只读解析，不访问任何远端接口、不上传任何数据。产品设计参考对象包括 llmcost、TokenBurn、tokentop、token-dashboard、ai-usage-dashboard、TOKEN-METER、llm.report、LiteLLM 及 Langfuse / Helicone / OpenLLMetry 等开源项目的公开说明（仅借鉴通用信息架构与功能模式，未复制其界面、文案或代码）。
